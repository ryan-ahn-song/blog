최초 검증은 로컬 코드·로컬 D1에서 수행했습니다. 이후 사용자 요청에 따라 `04c12e6`을 푸시하고 Cloudflare 연결 빌드로 운영 마이그레이션·API/웹 배포를 완료했습니다. 최종 운영 설정·도메인 전환·실측 확인은 [OWASP 재점검 기록](./owasp-review.md)을 참고하세요.

## 원인과 수정

- 세션: 세션에 발급 당시 login_version을 저장하고 매 요청에서 계정 버전과 비교합니다. 권한 변경, 작성자 승인, 로그인 수단 추가·해제 후 이전 세션은 사용할 수 없습니다. 연결 변경 후 현재 브라우저에만 새 세션을 발급합니다.
- 민감 작업: 최근 5분 내 OAuth 교환으로 인증된 서버 세션의 증명을 한 번 소비해야 계정 삭제·연결 해제가 가능합니다. 이메일 확인·최소 로그인 수단·마지막 관리자 보호도 유지합니다. 재인증은 기존에 연결된 동일 제공자 ID만 허용합니다. OAuth 제공자의 비밀번호/MFA 재입력 자체를 강제하는 기능은 아닙니다.
- 공개 권한: 정지 작성자의 포스트를 공개 목록·상세·검색·반응에서 숨깁니다. 관리자 검토 접근은 별도 권한으로 유지합니다.
- 인증 GET: 익명 /api/auth/me에서 만료 가입 티켓을 DELETE하던 동작을 없앴습니다. 만료 검증은 유지하며 정리는 매시간 Cron으로 옮겼습니다. 세션·로그인 제한·OAuth 상태도 정리합니다.
- 업로드: 파일당 8MB, 계정당 256MB/1,000개, 한 변 8,192px/2,400만 픽셀 한도를 검사합니다. D1에서 원자적으로 용량을 예약하고 R2 저장 실패 시 예약을 취소합니다. 과거 R2 파일도 첫 업로드 시 용량 집계에 포함합니다.
- 이미지 권한: /api/media에서 소유자·관리자 또는 공개 포스트/현재 프로필 참조 여부를 확인하고 R2 객체를 제공합니다. 리다이렉트하지 않으며 private, no-store로 공개 취소 후 캐시 노출을 방지합니다. 공개 참조는 post_media 인덱스를 이용합니다. 과거 본문 문서의 참조도 마이그레이션으로 채웁니다.
- 입력·브라우저: 가입/프로필 이름 검증을 NFC 정규화와 제어 문자 차단으로 통일했습니다. HTML에 CSP, HSTS, frame-ancestors/X-Frame-Options, nosniff, Referrer/Permissions Policy를 추가했습니다. 로그아웃 시 계정별 로컬 초안 백업과 캐시를 비웁니다.
- 목록: 목록 SQL/DTO에서 body, body_doc, 내부 쓰기 토큰을 제외했습니다. 제한된 excerpt와 reading_minutes만 제공합니다. 본문은 상세 조회에서만 읽습니다.
- 읽기: BlockNote 에디터를 생성하는 읽기 화면을 React 읽기 렌더러로 교체했습니다. 제목·문단·목록·체크박스·접기·표·코드·이미지·명시적 링크/영상 임베드·마크다운을 지원합니다. HTML 원문과 위험한 URL은 실행하지 않습니다. 에디터는 작성 시에만 로드합니다.
- 요청: 인증 확인 후 개인화 피드를 한 번 요청하고, 필자 목록은 해당 화면 진입 시 요청합니다. 숨겨진 읽기/작업 화면의 사이드바를 마운트하지 않습니다. 요청 중복 제거와 30초 메모리 캐시, 화면별 피드 보존을 적용했습니다. 계정·권한별 캐시 분리, 계정 전환 중 늦은 응답 폐기, 쓰기 후 무효화 및 수동 새로고침을 검증했습니다.
- D1: 대시보드의 독립 집계를 batch로 묶었습니다. 작성자 공개 포스트, 포스트별 일별 조회, 이미지 참조 및 만료 정리에 필요한 인덱스를 추가했습니다. 공개 주제/트랜딩만 짧은 HTTP TTL을 명시하며 개인화 응답은 no-store입니다. 실제 엣지 캐시 적중은 측정하지 않았습니다.
- 조회수: 쿠키·계정 제한 외에 Cloudflare가 제공한 IP 기반 버킷을 추가했습니다. X-Forwarded-For는 신뢰하지 않습니다. 정교한 분산 봇 차단을 대체하지는 않습니다.
- 임시 QA: 커밋에 포함되었던 .qa-* 실행 파일/진입점을 제거하고 ignore 처리했습니다. 해당 임시 서버도 종료했습니다.

## 운영 반영 결과와 후속 계측

1. 0014_security_performance.sql → 0015_media_references.sql → 0016_session_inactivity.sql이 연결 빌드의 원격 마이그레이션·배포 대상에 포함되었습니다. 운영 공개 API와 웹의 변경된 동작을 확인했습니다.
2. R2 공개 개발 URL과 media.21stark.dev 접근을 모두 비활성화했습니다. 기존 CDN 캐시가 남는 경우를 발견하여 해당 호스트를 WAF에서 차단하고 호스트 단위 캐시 Purge도 실행했습니다. 최종 앱의 /api/media 이미지는 200/private,no-store, 같은 이미지의 공개 원본은 403으로 확인했습니다. 외부에 이미 복사된 파일은 회수할 수 없습니다.
3. 실제 HTML에 CSP/보안 헤더가 적용되고 Google/GitHub 제공자 로그인 화면으로 진입하는 것을 확인했습니다. 계정 인증·동의 후 귀환 전체 흐름은 사용자 확인이 필요합니다. 로컬 Vite는 프로덕션 Worker 헤더를 적용하지 않습니다.
4. 메인 도메인에 무료 WAF API burst 제한을 활성화하고, 공개 API/웹 workers.dev와 preview URL을 비활성화했습니다. 두 도메인 TLS/HTTPS 설정도 강화했습니다. 유료 서비스·자동 결제·예산 한도 설정은 추가하지 않았습니다.
5. 데이터가 쌓이면 D1 Insights와 브라우저 Performance에서 rows_read, p95, LCP/INP를 계측해야 합니다. 현재 검색의 한국어 부분 문자열 의미는 유지했습니다. 본문 전체 검색의 FTS5/trigram 전환과 영구 집계 테이블은 운영 쿼리 비용·검색 품질을 확인한 뒤 결정합니다.

## 남은 한계

- 이미지의 형식/시그니처/치수는 검사하지만 서버에서 완전 디코딩·재인코딩하거나 EXIF를 제거하지 않습니다. 이를 강제하려면 검증된 이미지 처리 파이프라인 또는 Cloudflare Images 설정이 추가로 필요합니다.
- 미사용 업로드도 계정 저장 한도에 포함됩니다. 자동 삭제는 동시 저장·다른 포스트 재사용 보호가 필요하여 이번에는 넣지 않았습니다. 계정 삭제 시의 내구성 있는 R2 정리는 유지됩니다.
- 대시보드는 기존 API 계약을 유지합니다. 영구 통계 집계 테이블·분할 API는 운영 쿼리 비용을 계측한 뒤 필요성이 확인되면 적용합니다.
- 민감 작업 재인증과 세션 버전 검증은 추가했지만 MFA 의무화나 제공자 측 재인증 강제는 아닙니다.
